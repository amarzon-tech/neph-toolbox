About

About this draft

Nephrology Toolbox is a clinician-facing collection of formulas used in nephrology. It is a draft for review by Dr Amar Damodar (Dr D). It is not for clinical use until he has signed off on every formula.

How it is built

  • Static web app that works offline (installable PWA). After the first load, it does not need a network.
  • No login, no ads, no analytics, no data collection. Inputs stay in memory on this device and are not stored.
  • Every formula is taken from its original or guideline source. The equation, citation (with DOI / PubMed), and limitations are in each calculator’s info panel, and again in CONTENT_REVIEW.md for sign-off.
  • A DRAFT=true flag in the code drives the banner at the top of every screen.

Privacy

This app makes no network calls for calculations and does not send, save, or share patient data. Citation links (DOI, PubMed) open only if you choose to follow them.
